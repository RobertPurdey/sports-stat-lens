# Sports Stat Lens Web
React frontend for exploring and investigating sports data.

---

## Local

```bash
cd apps/web
npm install
npm run dev
```

Open `http://localhost:5173`.

```bash
npm run lint
npm run build
npm run preview
```

---

### Docker

Build and run from `apps/web`:

```bash
docker compose up --build
```

Open `http://localhost:5173`.

Stop the container with `Ctrl+C`, or run:

```bash
docker compose down
```
